# LiDAR-to-Heightmap Tutorial Website

This repository contains the Astro source code for the website version of the LiDAR-to-Heightmap Tutorial.

The tutorial itself, including the scripts, example data, and documentation, is maintained in the [main project repository](https://github.com/KingStu90/LiDAR-to-Heightmap-Beginner-Tutorial).

The website is automatically built and deployed using GitHub Pages.
